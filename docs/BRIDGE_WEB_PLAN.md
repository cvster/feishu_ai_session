# 个人 AI 会话群网页

已实现轻量网页：工具 → 项目 → 会话三级侧边栏，只展示绑定个人 AI 会话群的活跃会话。支持搜索、聊天、实时回复、双向名称同步和手机布局。工具名称取自 worker manifest，不在页面维护工具列表。

## 启用

在完成桥接版本部署后，为对应 profile 配置网页：

```bash
lark-channel-bridge web configure --profile <profile>
# 从源码运行时：node dist/cli.js web configure --profile <profile>
lark-channel-bridge web status --profile <profile>
```

默认地址 `http://127.0.0.1:3345`，本机回环访问免登录，页面直接进入会话且不显示退出按钮。配置其他本机 IPv4 地址时，configure 只显示一次随机登录码，磁盘仅保存其 SHA-256 摘要。随后启动或重启**桥接服务**即可访问，无需单独运行前端服务；configure 本身不重启服务。已有 worker 不随桥接重启。

可用 `--host <本机IPv4> --port <端口>` 指定监听地址，禁止 `0.0.0.0`。局域网 HTTP 适用于可信私网；默认使用本机回环。跨网络访问建议用 SSH 转发回环端口，例如 `ssh -L 3345:127.0.0.1:3345 <host>`。当前入口按配置 IP/localhost 校验 Host，不支持直接套用任意域名反向代理。

支持通过 `--also-host <本机IPv4...>` 同时监听多个网卡，通过 `--trusted-network <IPv4 CIDR...>` 配置免登录来源。例如本机与 `192.168.188.0/24` 网段免登录：

```bash
lark-channel-bridge web configure --profile <profile> --host 127.0.0.1 --also-host 192.168.188.1 --trusted-network 192.168.188.0/24
```

免登录判断使用 TCP 连接的真实来源地址，不信任 `X-Forwarded-For` 等代理头。其他来源继续使用登录码；免登录请求同样接受 Host、同源和所有者校验。配置中的 `additionalHosts` 和 `trustedNetworks` 可选，旧配置保持原有行为；变更监听地址或免登录网段立即撤销现有访问，重启桥接后生效。

非回环入口的登录 cookie 为 HttpOnly、SameSite=Strict，12 小时过期。登录会话绑定 profile、配置摘要及当前机器人所有者；更换登录码、禁用入口或所有者变化会撤销旧登录。配置文件在 `profiles/<profile>/web.json`，权限 600。

```bash
lark-channel-bridge web disable --profile <profile>
```

禁用立即拒绝 API 并关闭 SSE；服务下次重启后不再监听。改变监听地址需重启桥接。不要将 worker token 或飞书应用凭据填入网页登录框。

## 通信与边界

```text
网页 ── HTTP / SSE ── 桥接服务 ── 统一 worker HTTP ── 原生工具
                         │
                         └── 飞书消息、群名同步
```

- `apps/bridge-web/page.ts`：无构建依赖的原生 DOM 页面，随 CLI 打包，不执行工具命令。答案以安全文本和代码块展示，不执行消息里的 HTML；不展示思考或工具详情。
- `src/web/server.ts`：127.0.0.1 本机免登录、其他地址 cookie 登录、Host/Origin 检查、JSON 请求限制、登录限流和 SSE。多个浏览器共享按会话的观察结果，慢连接会断开并重新读取快照。
- `src/web/service.ts`：统一 `list/read/send/rename/control/favorite`，依据绑定、账户和 worker capabilities 授权。会话身份包含 profile、应用、群、工具、sourceId 和 nativeId，页面持有其摘要。归档/共享/辅助/话题群被排除，已失效群沿用现有群清理流程。读取失败不会被当成归档。
- `src/bot/intake-queue.ts`：飞书和 Web 共用持久化收件箱、去重和 PendingQueue。执行、会话锁、回复卡片、完成时艾特所有者沿用原桥接路径。网页文本中的 `/exit` 等仅作为模型输入。
- worker：读取原生记录、处理执行及工具协议。Claude 和 Dsh 补充了 conversation；Kilo 补充原生轮次与 job 的关联，Zcode 通过已使用的原生输入元数据关联 job。桥接仅接受可由 worker journal 验证的 job 关联。

侧边栏每个会话右侧提供“⋯”菜单，可修改会话名、归档和复制，无需切换当前对话。操作与确认按钮绑定点选的会话，切换会话时忽略迟到结果。输入框左侧仅保留停止、刷新两个按钮，右侧发送按钮加高并居中对齐。`src/web/controls.ts` 将现有命令卡片转换为网页表单和按钮，复用相同命令处理器；复制选项和归档确认均在网页完成。后续按钮使用服务端签发、绑定当前会话及所有者的 15 分钟令牌，仅允许已展示的命令和表单选项；提交重试复用结果。归档确认展示两个红色按钮：归档保留群和历史，归档并解散群先归档再解散群、清理关联，保留原生会话历史。飞书卡片仍采用快速返回、异步更新的回调流程。

新增 Web/UI/服务没有按 Codex、Claude、Zcode、Kilo、Dsh 分支。操作由 `conversation`、`sessions.rename`、`nativeSessionNames`、`jobs.submit` 决定。新增 worker 实现统一协议和能力声明后无需修改网页。桥接既有历史工具兼容代码仍存在，例如 Codex 名称账本旧键。

## 消息与状态

网页先以机器人消息在个人群发送“来自网页”，再将同一消息 ID 放入正常持久队列。HTTP 202 表示排队，页面随后区分工具接收、执行、完成、失败及状态待确认；问答待处理时提示前往群或原工具。

请求 ID 在浏览器本地保存到确认排队，重试复用原 ID；服务端账本只保存请求指纹、身份和群消息回执，完整消息使用现有 inbox。群投递使用稳定 UUID；未知结果超过 55 分钟暂停自动重发。若群发送后绑定变化，拒绝后续执行，已发送的群消息保留供检查。

聊天读取统一 native conversation 和 worker job 游标；桥接输入使用 inbox 中的原消息，不展示执行 prompt 的策略/上下文。可关联的原生轮次按 job ID 去重。历史中无法确认来源的桥接输入不展示，其较早的回答可展示；来源不明确的输入不会被回推到飞书。Claude SDK 来源按不确定来源处理，已确认 CLI/VS Code 输入可回推；Dsh 使用原生 source 元数据区分已标记的桥接输入。

SSE 每秒共享读取订阅中的会话；完成的 job 复用缓存和事件游标，不重复扫描完整事件。断线后重新获取权威快照，断开网页或桥接观察不取消 worker 任务。worker 离线时保留绑定项、禁止发送；运行中已有历史在内存缓存保留，桥接重启且 worker 离线时需等待恢复才能读取原生历史。

网页在当前标签页内存中缓存最近 20 个已加载会话的内容和滚动位置。切换回来立即显示缓存，由 SSE 获取最新内容；首次打开才请求历史。切换和更新使用即时滚动，阅读历史时保留当前位置，接近底部时跟随新回复。过期请求不会覆盖新会话或较新的实时快照；绑定失效、登录身份变化时清理缓存，刷新网页后重新加载。

## 名称

网页改名与现有名称观察串行执行，同步原生会话和个人群并保存基线。原生改名成功、群改名失败时，后续扫描会重试群改名；两端成功后忽略旧快照回声。群/工具端改名继续使用 15 秒轮询，随后更新网页；同时修改沿用群名优先规则。

## 验证

`tests/integration/web/personal-web.test.ts` 使用真实本地 worker HTTP、持久 inbox、公共队列、群投递替身和 HTTP/SSE；覆盖五个 worker 的网页停止、设置保存/预览、复制选项和归档确认，及 Codex、Zcode、Kilo 的三端消息、三处名称、并发去重、重启恢复、绑定失效、离线、本机免登录、非回环认证、同源/Host 校验、入口禁用、令牌重试及跨会话拒绝。Claude/Dsh 记录适配另有解析测试，Dsh 有原生协议进程夹具测试。浏览器验证登录、发送/回复、改名、会话切换、HTML 文本安全以及手机布局。

这些是隔离集成/浏览器验证。真实飞书群及真实模型的 Web autotest 尚未执行；代码交付不自动部署或重启生产服务。旧 worker 未提供新能力时，页面会保留桥接聊天并提示原生对话读取不可用。

侧边栏名称每 15 秒读取真实个人群名，独立于 worker 改名能力和旧绑定名称；飞书查询短暂失败时保留最近确认的群名，并将写入入口标为不可用。名称同步的正常检查也会回填旧绑定名称，即使原生会话和群已经同名。

侧边栏开头固定提供“收藏 → 项目 → 会话”，同项目的不同工具会话汇总展示；原工具列表仍保留会话。
每行的工具图标直接复用飞书群头像的 PNG，星标使用饱满的五角星，收藏后亮起。收藏按钮不切换或加载对话。
`POST /api/sessions/:id/favorite` 显式设置布尔 `favorite`，重复设置幂等。收藏保存在桥接端
`web-receipts.json`，按所有者和稳定会话身份隔离，刷新、重启和不同网页入口共用，SSE 同步状态。
旧账本没有 `favorites` 字段时兼容读取；归档或失效绑定的收藏不再显示，不影响原历史。

收藏下方默认显示“最近更新 → 项目 → 会话”，收录全部可见个人会话中最近更新的 9 个，包含收藏会话。
按统一 worker 的 `updatedAtMs` 排序，桥接新输入也计入更新时间，原生列表刷新后通过 SSE 同步。
不会把目录扫描时间作为原生会话活动时间。搜索只过滤已入选的最近会话，不把旧会话补进列表。
侧边栏底部“设置”可关闭最近列表，或将数量设为 1–50；设置保存在当前浏览器、当前网页地址的本地存储。
桌面侧边栏默认宽度 325px，可拖动右边缘或用方向键调整；宽度记在同一份本地设置中，双击边缘恢复默认。
窄屏自动限制宽度，手机仍使用展开式侧边栏。
