# Windows launcher resources

- `codex-blue.png`: transparent blue recolor of the locally installed Codex icon, produced with imagegen.
- `codex-blue.ico`: multi-resolution Windows shortcut icon (16, 24, 32, 48, 64, 128, 256 px), converted from that PNG.

These are unofficial local shortcut resources, not a replacement for the installed App's resources or an official alternate Codex distribution. The original application files are not modified. OpenAI/Codex marks remain their owners' property.

No account credentials, machine paths or runtime state are embedded in these files.
